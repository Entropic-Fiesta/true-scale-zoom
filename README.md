# True Scale Zoom

A Blender add-on that zooms the 3D viewport so **1 m in the scene is 1 m on your physical screen**. Handy for judging the real size of a model while you design it.

Tuned for the MacBook Air (M1, 2020) display. It can auto-detect the macOS "Looks like" resolution, and a ruler calibration covers other screens.

- **Blender:** 3.6 or newer
- **Location:** 3D Viewport → Sidebar (N) → View tab, and the View menu

## Install

1. Download `true_scale_zoom.py`.
2. In Blender, open **Edit → Preferences → Add-ons**, choose **Install from Disk**, and pick the file.
3. Enable **True Scale Zoom**.
